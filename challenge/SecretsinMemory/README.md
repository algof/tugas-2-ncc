## Description

Sebuah data rahasia milik Novus sudah dienkripsi menggunakan teknik AES (Advanced Encryption Standard). Sayangnya, key dan beberapa informasi lainnya tersimpan di memori komputer sebelum akhirnya dihapus. Tugasmu adalah menemukan key tersebut di dalam memory dump yang diberikan, lalu menggunakannya untuk membuka file yang terenkripsi dan mendapatkan flag.
